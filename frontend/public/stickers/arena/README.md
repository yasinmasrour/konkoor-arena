# Griffin Arena stickers

Place the custom sticker assets in this folder using these exact filenames:

- sticker-01.webp
- sticker-02.webp
- sticker-03.webp
- sticker-04.webp
- sticker-05.webp
- sticker-06.webp
- sticker-07.webp
- sticker-08.webp

You can replace the catalog and filenames later in `src/constants/arenaStickers.js` on the backend and `src/pages/Arena/components/ArenaStickerPanel.tsx` on the frontend if you want a different set.
