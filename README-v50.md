# Griffin Academy — V50

## Question Designer: Preview & Review

V50 upgrades the Question Designer preview into a review workspace.

### Added
- Student preview mode: hides correct answer and explanation.
- Review mode: highlights the correct option and shows the explanation.
- Review checklist for required question fields.
- Question metadata panel: lesson, grade, major, chapter, topic, status.
- Source information in review mode.
- Current question status is loaded from the backend and shown in the designer.
- Responsive preview modal for desktop and mobile-sized layouts.

### AI policy
- No AI Assistant was added to the Question Designer.
- No new AI API calls, tokens, or AI-related dependencies were introduced by V50.
- The existing AI Analysis feature for exam results remains separate and unchanged.

### Backend / Database
No backend code, API contract, Prisma schema, or migration was changed in V50.

### Math
The existing MathText, MathEditor, and MathFormulaBuilder from previous versions remain unchanged and continue to power formula rendering and editing.
